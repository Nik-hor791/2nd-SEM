### Вариант №5 (Транспорт) 
### Класс Bus:
Класс Bus моделиует автобус и содержит следующие атрибуты:


    number - номер автобуса, указывается в формате int

    capacity - вместимость автобуса, указывается в формате int

    route - описание пути автобуса, указывается в формате str

    year - год выпуска автобуса, указывается в формате int
